FontAwesome Purge Test

Diese Seite demonstriert die Verwendung der bereinigten FontAwesome CSS-Datei. Nur die unten gezeigten Icons (und die Basis-Klassen) sollten im CSS enthalten sein.

fa-house (Solid)
fa-user (Solid)
fa-check (Solid)
fa-house fa-lg (Utility-Klasse Test)

Hinweis: Damit die Icons tatsächlich angezeigt werden, müssen die entsprechenden Font-Dateien von FontAwesome im richtigen Verzeichnis (relativ zum CSS) vorhanden sein. Dieser Test prüft primär das Vorhandensein der CSS-Selektoren.
